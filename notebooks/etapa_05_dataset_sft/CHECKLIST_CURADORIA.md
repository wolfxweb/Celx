# Checklist de curadoria

## Fidelidade

- [ ] Descreve somente comportamento visível no código.
- [ ] Não inventa validações, exceções ou efeitos colaterais.
- [ ] Condições, comparações e operações estão corretas.
- [ ] A referência pública foi usada apenas como apoio.

## Formato

- [ ] Está em português e possui resumo.
- [ ] Contém `### Objetivo`.
- [ ] Contém `### Parâmetros`.
- [ ] Contém `### Retorno`.
- [ ] Contém `### Funcionamento`.
- [ ] Contém `### Regras de negócio identificadas`.
- [ ] Contém `### Pontos não determinados`.

## Aprovação

- [ ] O revisor foi identificado.
- [ ] As dúvidas estão em `review_notes`.
- [ ] O exemplo não pertence ao benchmark.
- [ ] O split está correto.
- [ ] `review_status` foi alterado para `approved` somente ao final.
